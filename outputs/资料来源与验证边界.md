# 资料来源与适用范围

以下资料检索于 2026-11-05，用于解释时序与对照同型号记录。它们不构成本仓库配置通过厂家或 VESA 认证的证明。

## 工具与时序原理

| 来源 | 用途 |
|---|---|
| [CRU 官方说明](https://www.monitortests.com/forum/Thread-Custom-Resolution-Utility-CRU) | EDID 覆盖、DisplayID 高像素时钟时序、驱动重载与恢复。写入、驱动接受和实际逐帧显示需分别检查。 |
| [ToastyX：Timing parameters explained](https://www.monitortests.com/blog/timing-parameters-explained/) | 前沿、同步宽度、后沿与像素时钟的关系。 |

两份 linuxhw 文件均有重复拼接的 EDID 段。比较时应取前面的完整三块，避免把整段重复数据直接导入 CRU。公开 EDID 采集记录只能说明设备声明的模式，不能证明采集时正以该模式运行。

在本次检索范围内，未找到相同 Intel 平台、相同低消隐参数且完成长期验证的其他成功记录。

## 原厂资料的缺口

[Panelook 目录](https://www.panelook.com/NE160QDM-NZL_BOE_16.0_LCM_overview_68607.html)列有 **NE160QDM-NZL V18.0_Rev.P1**。本项目未取得可公开核对的完整原厂正文，因此前后沿和消隐的允许范围仍未知，尤其不能确认水平后沿为 0 是否处于原厂保证范围。

单条 EDID 时序不等于面板的完整工作边界；动态范围块也不宜直接解释为物理像素时钟的绝对下限。文件中 Windows 的 `bpp: 32` 字段同样不能用于判断 eDP 链路色深、DSC 或链路速率。

## 测试方法

- [TestUFO Frame Skipping](https://www.testufo.com/frameskipping)：使用 `READY` 状态下的长曝光照片检查帧序列；操作步骤见[显示检查](手动参数与恢复.md#显示检查)。
- [VESA Adaptive-Sync Display CTS r1.1](https://vesa.org/wp-content/uploads/2023/05/Adaptive-Sync-Display-CTS-r1.1.pdf)：2023 年公开测试规范，含时序与视频掉帧检查方法。
- [VESA 2023 年首尔工作坊](https://vesa.org/wp-content/uploads/2023/11/VESA-October-2023-Seoul-Workshop-Presentations.pdf)：PDF 第 48 页介绍 CVT，第 65–66 页展示长曝光帧序列和抖动检查。

本仓库已保存 Windows 模式读数与文件校验结果，独立物理跳帧和长期稳定性测试仍待完成。家用照片检查不能等同于完整 CTS 测试；严格的光学刷新测量还需校准的高速拍摄或光电设备。
